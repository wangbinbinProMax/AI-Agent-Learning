# day01_初始智能体

## 需要搞明白的几个问题

- 智能体是什么？
- 它有哪些主要的类型？
- 它是如何与我们所处的世界交互的？

### 智能体的定义：

任何能够通过**传感器（Sensors）**感知周围**环境**，并**自主**通过**执行器（Actuators）**采取行动以达到目标的任何实体。

### 它有哪些主要的类型：

- 基于目标的智能体（GPS）
- 基于模型的智能体
- 基于效用的智能体
- 学习型智能体（Alpha Go）
- **大语言模型**

### 大语言模型：

LLM智能体通过海量数据训练，获得了**隐式的世界模型**与强大的**涌现**能力

LLM智能体接收到任务后，其工作方式提现了以下几点：

- 规划与推理
- 工具使用
- 动态修正

### 智能体有三种分类方式：

1. 基于内部决策架构的分类

2. 基于时间与反应性的分类

   代表有:**反应式智能体**，**规划式智能体**，**混合式智能体**

3. 基于知识表示的分类

   代表有：**符号主义**，**亚符号主义**，**神经符号主义**

   大语言模型驱动的智能体是神经符号主义的一个极佳实践范例。其内核是一个巨大的神经网络，使其具备模式识别和语言生成能力。然而，当它工作时，它会生成一系列结构化的中间步骤，如思想、计划或 API 调用，这些都是明确的、可操作的符号。通过这种方式，它实现了**感知与认知、直觉与理性**的初步融合

### 智能体构成与运行原理

#### 任务环境（Environment）：

确定性和随机性

#### 智能体的运行机制：

智能体循环

1. **感知**
2. **思考**
   - 规划
   - 工具选择
3. **行动**

#### 智能体的感知与行动：

明确一套交互协议，规范智能体与环境的信息交换

- **思考**
- **行动**

例子：

```python
Thought: 用户想知道北京的天气。我需要调用天气查询工具。
Action: get_weather("北京")
```
